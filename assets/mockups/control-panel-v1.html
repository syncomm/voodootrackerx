Design Token Reference — VoodooTracker X Control Panel v1
Color Palette
#252526 panel
#181819 readout
#C9A74A gold
#E8D8A0 values
#4DB868 play
Visual Hierarchy
Readout fields (LEN, RST, TITLE, CHN, TIME) use background #181819 with gold border at 22% opacity — visually recessed, inert.

Interactive fields (TEMPO, SPEED, ROWS, POS, popups) use #1C1C1D with gold border at 55% — tactile, reachable.

The 1px gold accent line at the top of the panel anchors the entire strip visually.
Transport Button States
PLAY active: bg #152A1A, text #4DB868 — green glow indicates song is playing.

STOP dim: very muted red tint — available but not the focus state.

LOOP on: bg #2B2514, text/border #C9A74A — gold active state.

EDIT off: subtle, muted. Becomes gold when toggled on.
Typography
All text: SF Mono / monospace only.

Labels: 10.5px, weight 700, ALL CAPS, gold #C9A74A.

Values: 11.5px, weight 500, warm near-white #E8D8A0.

Buttons: 10.5px, weight 700, ALL CAPS.

Tracker grid: 9px monospace for row content.
Group Separators
1px vertical lines at gold 38% opacity (rgba(201,167,74,0.38)) with 10px horizontal margin each side.

The separator before the TIMING group (TEMPO/SPEED) uses 55% opacity and 12px margins — these are the primary live-editing controls and deserve extra breathing room.
Widget Decisions
TEMPO + SPEED: editable NSTextField + NSStepper (range 32–255 and 1–31). Currently read-only — this must change.

ROWS: add NSStepper. Common values: 16, 32, 64, 128, 192, 256.

PATTERN, INST, SMP, OCT: NSPopUpButton (keep, correct widget).

TIME: split from TITLE string — new separate readout field.
