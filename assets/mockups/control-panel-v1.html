Open Decision — Pattern Numbering Format
Option A — Decimal Recommended
PATTERN
012 ▾
→ "Pattern 12 of 111"
Zero-padded decimal (000–255). "012" is immediately readable by anyone. No hex knowledge required. The PATTERN label makes the context obvious. Works well when demoing to a mixed audience — non-tracker folks don't need to convert in their head. Most DAWs (Ableton, Logic, Reaper) use decimal for pattern/scene numbering.
Option B — Hex, no prefix Traditional
PATTERN
0C ▾
→ "Pattern 0C of 6F"
Hex without the P prefix (since the label already says PATTERN). More compact — "6F" vs "111". Authentic to XM/IT/FT2 tradition where everything is hex. If your audience is tracker folk or demoscene, this reads naturally. If you're demoing to general developers, requires a brief "that's hex" aside.
Design Token Reference — VoodooTracker X Control Panel v1
Color Palette
#252526 panel
#181819 readout
#C9A74A gold
#E8D8A0 values
#4DB868 play
Visual Hierarchy
Readout fields (LEN, RST, TITLE, TIME, CHN) — background #181819, border at 22% gold opacity. Visually recessed and inert.

Interactive fields (TEMPO, SPEED, ROWS, POS, all popups) — background #1C1C1D, border at 55% gold. Tactile, inviting interaction.

1px gold accent line at the very top of the panel anchors the strip visually.
INST / SMP Name Display
Closed popup shows: dim gold code (I01 / S01) + bright name (Drums / 808 Kick).

Name is truncated at ~12 chars with ellipsis. Full name appears in the tooltip on hover.

Opened dropdown items show: "I01 — Drums", "I02 — 808 Snare", etc.

When no name is set, the code (I01) fills the full value width — unchanged from current behavior.
Transport Button States
PLAY active: bg #152A1A, text #4DB868 (green glow).

STOP: muted red tint only when playback is running; dim otherwise.

LOOP on: bg #2B2514, text+border gold #C9A74A.

EDIT on: same gold treatment. Off state is visibly muted.
Widget Decisions
TEMPO (32–255) + SPEED (1–31): editable NSTextField + NSStepper. Critical for live editing.

ROWS: NSStepper. Common values: 16, 32, 64, 128, 192, 256.

PATTERN, INST, SMP, OCT: NSPopUpButton (correct widget, keep).

TIME: new separate readout — split from the TITLE string concatenation.
Group Separators
1px vertical, gold at 38% opacity, 10px margin each side.

Before TIMING group: 55% opacity, 13px margin — extra breathing room signals these are the primary live-editing controls.

Bottom row ends with a plain flex spacer (no content). No activity meters in the control panel — visualization belongs behind the logo.
