# VoodooTracker X v0.2.0-alpha.3 Release Notes

Release target: `v0.2.0-alpha.3`

Theme: Song / Order editor composition alpha.

This alpha marks the first VoodooTracker X build where a user can reasonably
compose a small song from scratch using editable blank documents, the main
pattern grid, transport controls, and the Song / Order editor.

## Highlights

- First-pass Song / Order editor composition workflow for editable blank
  documents.
- Pattern creation, duplication, clearing, viewing, and explicit Pattern Bank
  assignment.
- Order insertion, deletion, duplication, moving, and `PTN -/+` stepping through
  allocated patterns.
- `Transport > Play Current Pattern` for focused pattern audition through the
  existing runtime path.
- Improved editable blank-document composition flow with note entry, selected
  instrument/sample controls, note audition foundations, editable playback, and
  editable live-loop refresh.
- Loaded XM/MOD modules remain read-only for editing.

## Still Future Work

- Save/export from the app is not available yet.
- Full editing of loaded/imported modules remains future work.
- Instrument Editor and Sample Editor work remains future work, so true
  from-scratch instrument/sample authoring is not complete yet.
- This remains alpha-quality software and does not claim full FastTracker II,
  OpenMPT, or MikMod parity.

## Manual Release Smoke Checklist

Use only public fixtures or freshly created editable documents. Keep any
screenshots, logs, traces, WAVs, generated apps, DMGs, ZIPs, and local reports
under `/tmp` or another ignored local path.

- [ ] Launch the Debug app.
- [ ] Use `File > New`.
- [ ] Enter notes into pattern 0.
- [ ] Open the Song / Order editor.
- [ ] Use Pattern Ops `NEW`.
- [ ] Enter notes into the new unassigned pattern.
- [ ] Use Pattern Ops `DUP`.
- [ ] Use Pattern Ops `CLEAR` on the current pattern.
- [ ] Use Order Ops `INSERT`.
- [ ] Use Order Ops `DUP`.
- [ ] Use Order Ops `MOVE UP` and `MOVE DOWN`.
- [ ] Use Order Ops `PTN -/+`.
- [ ] Confirm Pattern Bank single-click view/navigation.
- [ ] Confirm Pattern Bank double-click assignment.
- [ ] Use `Transport > Play Current Pattern`.
- [ ] Use normal Play/Stop.
- [ ] Use Song / Order `CLEAR SONG` on an editable document.
- [ ] Load a public fixture and confirm it remains read-only for editor
  mutations.
- [ ] Confirm loaded-module Play/Stop/Loop still works.
- [ ] Confirm having the Song / Order editor open during playback does not
  reintroduce playback stutter.
- [ ] Confirm privacy/artifact scans are clean.

## Release Boundaries

This release-preparation PR should not change runtime playback, playback
scheduling, C mixer DSP, parser architecture, tracker viewport behavior,
loaded-module read-only behavior, save/export behavior, note entry, note
audition, or Song / Order editor app behavior. The maintainer should create and
push the `v0.2.0-alpha.3` tag manually after merge and final local smoke.
