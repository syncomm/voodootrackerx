# VoodooTracker X v0.2.0-alpha.4 Release Notes

Release target: `v0.2.0-alpha.4`

Theme: Export XM v1 for VoodooTracker X editable documents.

`v0.2.0-alpha.4` adds Export XM v1 for VoodooTracker X editable documents,
including the current supported song/order/pattern/note data and safely
represented existing instrument/sample payloads. This is not a full
arbitrary-XM round-trip guarantee. Loaded modules remain read-only, Save/Save
As remain disabled, and Instrument/Sample editors remain future work.

## Highlights

- `File > Export XM...` writes stopped editable documents to a user-chosen
  `.xm` destination.
- Export covers the current VTX editable subset: song/order data, pattern cells,
  note/instrument/volume/effect fields represented by the editable model,
  timing, channel/row dimensions, and supported existing instrument/sample
  payloads.
- Existing palette/sample payloads are included only where the editable model
  safely represents XM-derived signed 8-bit or 16-bit PCM with supported sample
  metadata.
- Exported XM files reopen through the existing loaded-module path as
  loaded/read-only modules.
- Loaded modules remain read-only for editing.

## Still Future Work

- Save and Save As remain disabled/deferred.
- Direct loaded-module editing remains deferred.
- Full arbitrary-XM round-trip parity remains future work.
- Full FastTracker II, OpenMPT, or MilkyTracker parity is not claimed.
- Instrument Editor and Sample Editor remain future work.
- Explicit loaded-module editable-copy behavior remains future work.

editable-copy paths. Keep screenshots, logs, traces, WAVs, generated XM files,
apps, DMGs, ZIPs, and local reports under `/tmp` or another ignored local path.

- [ ] If available, use a public/sample-bearing editable fixture or public-safe

- [ ] Reopen exported XM.

## Maintainer Post-Merge Tag Checklist

Do not create or push this tag from the release-preparation PR. After this PR
merges, the maintainer should run:

```bash
git checkout main
git pull --ff-only
swift test
./scripts/check-files.sh
./scripts/scan-tracked-private-leaks.sh
git tag -a v0.2.0-alpha.4 -m "v0.2.0-alpha.4 - Export XM v1"
git push origin v0.2.0-alpha.4
```

## Release Boundaries

This release-preparation PR should not change runtime playback, playback
scheduling, `PlaybackEngine`, `RuntimeCMixerAdapterEventPlan`, C mixer DSP,
parser architecture, loaded-module playback semantics, tracker viewport or
static-highlight behavior, Save/Save As availability, loaded-module
read-only/editability rules, Instrument Editor behavior, Sample Editor
behavior, or XM writer behavior.
