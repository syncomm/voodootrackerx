# VoodooTracker X v0.2.0-alpha.5 Release Notes

Release target: `v0.2.0-alpha.5`

Theme: Rendered Audio Export Alpha.

`v0.2.0-alpha.5` adds rendered audio export to VoodooTracker X. The app can
now export whole-song 48 kHz Float32 WAV files with the VTX render profile, a
3-second tail, auto-headroom, progress, cancellation, and performance
diagnostics, plus AAC-encoded M4A files for convenient sharing. Loaded modules
remain read-only, Save and Save As remain disabled, and advanced export options
such as ranges, stems, and custom export settings remain future work.

## Highlights

- `File > Export Audio > WAV...` renders the whole song as 48 kHz Float32 WAV
  using the VTX render profile, a 3-second tail, and export-boundary
  auto-headroom.
- WAV export provides weighted progress, cooperative cancellation, cleanup of
  temporary or partial output, and a concise performance summary diagnostic.
- `File > Export Audio > M4A...` reuses the completed scaled Float32 render and
  encodes AAC-in-M4A for convenient sharing, with progress and cancellation
  behavior consistent with WAV export.
- WAV remains the preferred high-quality and export-diagnostic format. M4A is
  intended as the convenient sharing format.
- Export is non-mutating and writes only to the destination selected by the
  user. It does not overwrite the opened source module or claim its path.
- Loaded modules remain read-only. Supported loaded XM modules can become an
  untitled in-memory editable document only through the explicit
  `File > Make Editable Copy` command.

## Still Future Work

- Save and Save As remain disabled.
- Direct loaded-module editing remains unavailable.
- Pattern/order-range export, stems, per-channel export, PCM16 product export,
  AAC bitrate or quality controls, user-selectable gain/headroom, and
  diagnostic render-profile selection remain future work.
- Export XM remains scoped to the current VTX editable subset; this release
  does not claim arbitrary-XM round-trip support or full FastTracker II,
  OpenMPT, or MilkyTracker parity.

## Manual Release Smoke Checklist

Use only a public-safe sample-bearing XM or generated fixture. Keep generated
WAV, M4A, XM, log, app, and screenshot artifacts under `/tmp` or another
ignored local path.

- [ ] Launch the app.
- [ ] Open a public-safe sample-bearing XM or generated fixture.
- [ ] Confirm the loaded module remains read-only.
- [ ] Confirm Save and Save As remain disabled.
- [ ] Use `File > Export Audio > WAV...` and choose a destination under
  `/tmp`.
- [ ] Confirm progress appears.
- [ ] Cancel once and confirm clean cancellation.
- [ ] Export WAV again without cancellation.
- [ ] Confirm WAV completes, plays externally, and is 48 kHz Float32 if easily
  inspectable.
- [ ] Use `File > Export Audio > M4A...` and choose a destination under
  `/tmp`.
- [ ] Cancel once and confirm clean cancellation.
- [ ] Export M4A again without cancellation.
- [ ] Confirm M4A completes and plays externally.
- [ ] Confirm Export XM still works for editable documents.
- [ ] Confirm generated WAV/M4A/XM/log/app/screenshot artifacts are not
  tracked.

## Maintainer Post-Merge Tag Checklist

Do not create or push this tag from the release-preparation PR. After this PR
merges, the maintainer should run:

```bash
git checkout main
git pull --ff-only
swift test
xcodebuild -project app/VoodooTrackerX/VoodooTrackerX.xcodeproj -scheme VoodooTrackerX -configuration Debug -destination 'platform=macOS' -derivedDataPath build CODE_SIGNING_ALLOWED=NO test
./scripts/check-files.sh
./scripts/scan-tracked-private-leaks.sh
git tag -a v0.2.0-alpha.5 -m "v0.2.0-alpha.5 - Rendered Audio Export Alpha"
git push origin v0.2.0-alpha.5
```

## Release Boundaries

This release-preparation PR changes documentation only. It does not change app
behavior, WAV or M4A export behavior, render PCM, runtime playback or live
gain, playback scheduling, C mixer DSP, parser architecture, tracker viewport
or static-highlight behavior, XM writer behavior, Save/Save As availability,
or loaded-module read-only rules. It does not create or push a git tag.
